# v1.8.0

PDF_Bookmarks 是 Windows 本地 PDF 书签工具，可独立处理普通 PDF，也适配 Zotero 附件。支持文字/扫描目录识别、JSON 导入编辑、预览校对、拖放和批量写入，保持原 PDF 文件名与路径。

本版修复两个标签页切换时窗口伸缩和移位，改善手动拖宽时的排版卡顿，整理界面并新增夜间模式；目录列表可按 Enter 批量确认并跳到下一待核对项，查找框也支持 Enter。面向 **Windows 10/11 x64**；Single 与 Portable GUI 功能相同，均无需安装 Python。发行标题仅使用版本号，七项附件继续沿用原下划线命名；历史发行版和附件保留。

## 更新内容

1. **切换标签页时保持窗口稳定**：主界面与目录工作台共用当前窗口尺寸、位置和最大化状态，切页不再恢复两套旧窗口几何设置。手动调整后另一页沿用当前尺寸；关闭重开工作台、保存JSON返回主界面也保持稳定。共用最小尺寸1000×760只在启动时设置一次；两页的置顶偏好仍分别保留。旧 `editor_geometry` 继续用于源码独立工作台接口，不被嵌入标签改写。
2. **改善连续拖宽的响应**：合并连续变化期间的内部排版，停止变化约80毫秒后按最终窗口尺寸更新，关闭时取消待执行布局。80毫秒只是合并等待，最终排版本身仍需时间；拖动中内容可能短暂保持旧尺寸、裁切或出现空白。这是减少逐像素重排的取舍，不承诺固定帧率、提速比例或OCR速度改善。
3. **整理界面并新增夜间模式**：统一蓝灰配色、输入边界、表格、间距和主要动作层次；主界面写入选项集中分组，目录工作台的查找与筛选分行，修正JSON路径栏过窄。两个页面顶部共享“夜间模式”，立即切换并记忆浅色/深色选择。编辑、历史、识别结果及PDF预览图像不因换肤重新生成；PDF页面保留原像素，不反色。Windows文件选择和系统提示框仍由系统绘制。
4. **Enter确认所选目录并继续校对**：目录列表获得焦点后，主键盘或数字键盘Enter确认所选一项，也可用Ctrl / Shift多选后一次确认多项。从最后所选项之后按原文档顺序定位当前搜索/筛选范围内的下一待核对项，末尾循环；没有待核对项时显示提示，可清空查找并切回“全部”继续。所选项存在未知/越界目标页或空标题时整批不确认；尚未填完的无效编辑保留。批量确认可一次撤销/重做，并沿用草稿暂存规则，不自动导出JSON或写PDF。
5. **Enter快速查找，保留编辑键用途**：查找输入框的主键盘和数字键盘Enter均执行“查找”，原按钮保留。下方编辑输入框及行内编辑的Enter继续只提交编辑，不触发目录批量确认或自动跳转；主界面输入不受目录列表局部按键绑定影响。

本版相对正式v1.7.0仅增量更新上述窗口、界面及快捷校对行为，未删减既有功能或改变目录识别算法。界面设计方法参考UI UX Pro Max、Anthropic frontend-design和微软Windows设计说明，具体固定版本、许可、阅读范围与采用内容见[界面设计说明](https://github.com/Zerozero05/PDF_Bookmarks/blob/v1.8.0/docs/UI_DESIGN.md)。沿用现有Tk/ttk、PyMuPDF与本地OCR，没有复制第三方主题实现、安装新技能或新增框架、模型及运行依赖。快捷确认复用原有校对、历史及草稿机制，没有新增外部借鉴。

## 继续保留的规范与功能

- 同一窗口两个标签页及原“生成 / 编辑目录…”入口；普通切换保留目录、未提交输入、历史、筛选和预览，不重新识别或载入。保存JSON后回主界面自动只读预览，仍须确认写入；关闭时保留草稿处理、取消及任务互锁，隐藏工作台仍阻止安装更新。
- 独立本地草稿、约1200毫秒合并自动暂存、手动暂存/恢复及Ctrl＋S；保留未确认条目和未完成输入，恢复核对原PDF路径、大小及修改时间，损坏/身份不符时保留原恢复文件。最多80步撤销/重做、查找筛选和详细表格/目录树继续可用。
- 自动/单栏/双栏布局、逐页框选识别区域和人工栏线；双栏按完整左栏再完整右栏读取，章节上下文跨栏、跨页继续，栏位置本身不决定层级。原目录行仅定位实际保留的识别来源，不伪造来源。
- 三种节编号：默认 `1.1 基本概念`、每章独立的 `1. 基本概念`、保留识别编号；编号与标题间一个空格，省略数字号前 `§`。手工标题及原有可靠编号保护继续有效，标题变化后重新确认。
- 滚轮滚动、Ctrl＋滚轮和按钮缩放50%–300%、适合宽度/整页、前后翻页、原目录行定位，以及可折叠的固定/分段页码映射。
- 正式目录JSON `version: 1`、CLI参数、批量配对、人工目标页确认和默认跳过已有书签。自动识别结果仍待核对，Enter是用户主动确认操作，不把OCR结果自动标为已核对。
- 预览只读；PDF按原路径临时副本写入、校验后原子替换。备份默认开启，删除输入JSON与茉莉花缓存仍为两个独立、默认关闭且只在成功后执行的选项。
- 原 `%LOCALAPPDATA%\ZoteroPDFBookmarks\settings.json` 与 `CONFIG_SCHEMA=1`。只新增有默认值的可选 `theme`（`light`/`dark`，默认浅色），旧字段、未知字段、设置位置及迁移/回滚保护保留；草稿与正式JSON分开。
- Single/Portable更新事务、下载校验、健康检查及程序/配置同步回滚；保留用户改名后的入口及发行类型。源码 `open_editor()` 的独立窗口兼容入口继续可用。

## 使用方法

1. 打开目录工作台，选择/拖入原PDF及已有JSON，或选择实际目录页范围、布局和节编号后识别。需要时先逐页框选目录区域、设置栏线再识别；重新识别会替换当前目录，先保留需要的编辑。
2. 对照右侧目标页核对标题、层级和页码。点击目录列表中的条目，按Enter确认并进入下一待核对项；多选后可整批确认。遇到未知/越界页或空标题先修正，不会跳过保护。
3. 在查找框输入标题文字后按Enter；结合待确认等筛选、目录树及来源行定位逐项核对。需要恢复时用撤销/重做，稍后继续时暂存草稿；草稿不替代正式JSON。
4. 按需切换夜间模式或调整窗口大小，切页继续使用当前窗口。核对并确认全部有效条目后保存JSON，回主界面预览无误再执行写入。

普通PDF无需安装Zotero。处理Zotero附件时，用“显示文件”定位原PDF，关闭该PDF阅读窗口后处理，再重新打开同一附件，无需重新附加；启用可选茉莉花缓存清理前须完全退出Zotero。

## 兼容性与限制

自动结果仍是待校对草稿，可信提示不是准确率保证。跨栏长标题、混合版式、模糊扫描、数学符号、上标、缺页及未标印刷页码条目可能需要手工处理；区域和栏线不能代替标题、层级与实际目标页核对。识别不等于已逐页校验正文，保存前应抽查章首、跨栏衔接和末尾页。

夜间模式只调整程序外观，不修改PDF或系统主题。拖宽合并布局减少频繁排版，不能消除不同设备、DPI及复杂内容下的全部延迟。程序仍受Windows路径长度限制，过深的程序/临时目录可能导致文件操作失败。

OCR、草稿与PDF处理在本机运行，不上传文献，不需要API Key。草稿可能含文献标题和本地路径，属于用户未完成工作；仅复制EXE不会迁移设置和草稿，恢复草稿还需原PDF身份匹配。

## 从旧版升级

v1.5.0及后续Single/Portable GUI可通过“帮助 / 更新”检查已公开正式版本，下载校验后由用户选择安装并重启，保留发行类型、实际入口名称与原设置。安装前保存目录并关闭工作台内容，等待识别、预览、保存及PDF写入任务结束；仅切回主界面不等于已关闭工作台。CLI/源码从发行页手动更新。

v1.4.1没有自动更新入口，须手动下载本版。Single运行新EXE；Portable完整解压新文件夹，不能只复制主EXE。旧程序目录中的用户PDF、目录JSON、备份及其他资料继续保留。

## 验证与证据范围

- **本轮源码回归**：505项，504通过、1项跨盘环境测试跳过、0失败。包含Enter单/多选、筛选与目录树原始索引、回绕、无效页/空标题整批拒绝、撤销/重做、草稿、搜索/编辑键隔离、稳定窗口、合并排版、明暗主题及已有PDF/CLI/更新回归；跳过项不算通过。
- **同功能本地试用**：1.7.0身份的实际EXE通过297项PYZ内嵌模块检查及27项运行源码指纹、身份/资源/helper核验；模块检查使用宿主Python/Tk/OCR依赖，不等于全部冻结GUI端到端验证。普通Return使用真实Tk事件；Windows Tk无法合成独立KP_Enter键码，数字键盘检查调用实际注册Tcl绑定，不宣称物理数字键盘实测。
- **试用确认**：用户于2026-10-18明确表示确认完毕并授权发布。代理最后一次实际窗口Enter交互曾因用户物理Esc停止，结果未知，立即停止控制；该历史记录保留，不记为代理完成全部实际窗口验收。
- **正式1.8.0与云端**：发布前须重新核对生产版本身份、资源、包内源码和七项资产，由工作流执行完整源码回归及真实冻结Single/Portable成功升级、健康失败回滚共四场景，检查草稿资产后才公开。准备阶段未预报这些结果通过；实际状态见对应[Windows Actions](https://github.com/Zerozero05/PDF_Bookmarks/actions/workflows/windows-build.yml)及[验证记录](https://github.com/Zerozero05/PDF_Bookmarks/blob/v1.8.0/VALIDATION.md)。
- **历史证据与未覆盖项**：正式1.7.0的237项包内检查、四种构建身份及4个冻结更新场景属于历史记录；原实书自动/人工栏线各147项、20章、偏移+8仅限该样例。完整冻结GUI的实书OCR与PDF写入交互未逐项实操，单个样例、有限回归和用户确认均不保证任意文档或Windows环境绝无缺陷。
